# SWIPE FORCE

Retro vertical scrolling shooter built with **Grok Build iOS**.

## Play

- **Swipe / V-Stick** to move (OPTIONS → V-STICK)
- Auto-fire weapons
- Side bezel → shop anytime
- Defeat bosses, spend PTS on upgrades
- Weapon strength levels via left/right swipe in OPTIONS

## Stack

React 19 · TanStack Start · Vite · Canvas 2D · Web Audio (procedural SFX/BGM)

## Scripts

```bash
npm install
npm run dev      # http://0.0.0.0:8080
npm run build
npm run typecheck
```
